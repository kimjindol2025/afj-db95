# DB95 191 Coding 기획서

기준: DB95 native-run c315ef23, FX fix/db95-23-nocurl a9ffce18.

목표는 두 확인된 원인을 수정하고 지정된 원본 시험 및 별도 검증으로 결과를 확인하는 것이다. 전체 71건 통과나 제품 완성을 주장하지 않는다. 프로젝트 AGENTS.md의 단계 경계상 메모리 기반 코어 단계이며, 영속성·트랜잭션·네트워크 서버의 제품 완성은 이 작업의 검증 범위가 아니다.

1. 행 버전: afj-tcp-row-map은 일반 map을 반환하지만 호출부가 다시 deref한다. native fl_deref는 일반 map을 nil로 처리한다. 이 때문에 기존 버전만 닫히고 새 버전이 추가되지 않는다. case 38/41/42와 checkpoint 이전·현재 버전 복원을 검증한다.
2. 반복 횟수: native 산술식은 FL_FLOAT를 반환하지만 fl_repeat는 FL_INT만 받는다. (+ 1048576 1)이 반복 횟수 0이 되어 WAL padding이 빈 문자열이 된다. 산술식 횟수로 padding 길이 1048577을 보존하고 case 7/13을 검증한다.

원본 시험·기대값·러너·제한시간은 유지한다. case 9는 node/awk 금지 위반 해소 및 승인 전까지 HOLD다. 기존 변경사항을 보존하며 동일 원인 3회 실패 시 즉시 중단한다. 검증 PASS 전 커밋·푸시·배포를 금지한다.
